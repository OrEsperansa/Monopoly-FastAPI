# תרגיל 6: השפעות משבצות

## מטרת התרגיל

להפעיל את סוג המשבצת שעליה השחקן נחת. אין נקודת קצה חדשה: מרחיבים את `POST /api/game/roll` מתרגיל 4.

## התנהגות נדרשת לפי סוג

- `reward`: מוסיפים לשחקן בדיוק את `amount` של המשבצת.
- `penalty`: מפחיתים מהשחקן בדיוק את `amount` של המשבצת.
- `surprise`: מפעילים תוצאת הפתעה ומוסיפים אירוע שמכיל את המילה המדויקת `Surprise`.
- `property` פנוי: הנחיתה אינה קונה את הנכס. אין לשנות את כספי השחקן או את הבעלות, ו-`owner_id` נשאר `null`. יש רק להציע לשחקן את האפשרות לקנות באמצעות `available_actions` ששווה בדיוק ל-`["buy", "end_turn"]`, בסדר הזה.
- `start` או משבצת שאין בה אפשרות קנייה: הפעולה הזמינה לאחר הטיפול היא `end_turn` בלבד.

כל השפעה נשמרת ב-`state` המלא שמוחזר. `last_event` הוא תמיד האיבר האחרון ב-`event_log`.

הרכישה עצמה מתבצעת רק לאחר בקשה נפרדת אל `POST /api/game/buy`, כאשר השחקן בוחר לקנות. נקודת הקצה הזאת תמומש בתרגיל 7; בתרגיל 6 נדרש רק להציע את הפעולה `buy` ולא לבצע אותה.

## מה עושה משבצת Surprise

כאשר שחקן נוחת על משבצת מסוג `surprise`, יש לבחור באקראי **תוצאה אחת בלבד** מתוך הרשימה הבאה ולהפעיל אותה מיד:

- `gain_100`: השחקן מקבל 100 כסף.
- `lose_50`: השחקן משלם 50 כסף.
- `collect_50`: כל שחקן אחר שלא פשט רגל משלם לשחקן הנוכחי 50 כסף.
- `pay_25`: השחקן הנוכחי משלם 25 כסף לכל שחקן אחר שלא פשט רגל.
- `forward_2`: השחקן מתקדם שתי משבצות.
- `backward_2`: השחקן חוזר שתי משבצות.

לאחר הפעלת התוצאה, `available_actions` חייבת להיות בדיוק `["end_turn"]`. יש להוסיף ל-`event_log` אירוע אחד שמתאר את התוצאה ומכיל את המילה המדויקת `Surprise`, ולהציב את אותו אירוע בדיוק ב-`last_event`.

לדוגמה:

```text
Surprise: Ada received 100.
Surprise: Ada paid 50.
Surprise: Ada moved forward 2.
```

האירוע צריך לתאר את התוצאה שבאמת נבחרה. אין לשנות בעלות על נכסים כחלק מהפתעה, ואין להציע `buy` רק משום שתנועת ההפתעה הסתיימה על נכס פנוי.

## אופן כתיבת הקוד

יש לממש את ההתנהגות הנדרשת תוך שמירה על חוקי SOLID. מצאו Design Pattern שמתאים לתרגיל, הסבירו למה הוא מתאים ולאחר מכן ממשו אותו.

## דרישות שנשארות בתוקף

הקובייה, התנועה המעגלית, בונוס Start, מעטפת התגובה `{"state": ...}` וחסימת זריקה חוזרת ממשיכים לפעול לפי תרגיל 4. מעבר התור ממשיך לפעול לפי תרגיל 5. הלוח נשאר הלוח בן 16 המשבצות מתרגיל 2.

## כיצד לוודא שהתרגיל הושלם

הריצו משחקים חדשים וזריקה ראשונה עד שתצפו בכל אחד מהסוגים reward, penalty ו-surprise. בכל מקרה השוו את הכסף או המיקום לערכי המשבצת. בנחיתה על נכס פנוי בדקו יחד את הכסף, `owner_id` ורשימת הפעולות כדי לוודא שלא התבצעה קנייה אוטומטית.
