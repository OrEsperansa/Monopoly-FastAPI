# תרגיל 4: קובייה, תנועה ובונוס Start

## מטרת התרגיל

להוסיף תור משחק ראשון: השרת מגריל קובייה אמיתית, מזיז רק את השחקן הנוכחי במסלול מעגלי ושומר את המצב החדש.

## נקודת הקצה החדשה

### `POST /api/game/roll`

הבקשה אינה כוללת גוף או כותרת בדיקה מיוחדת. התגובה התקינה מחזירה קוד `200` ואת מצב המשחק המעודכן בתוך המפתח `state`:

```text
{
  "state": <מצב המשחק המלא לאחר הזריקה>
}
```

האובייקט שבתוך `state` חייב להיות `GameState` מלא עם שמונת השדות שהוגדרו בתרגיל 2. אין להחזיר את `GameState` ישירות; גוף התגובה חייב להכיל בדיוק את המפתח `state`.

## כללי התנועה

- מותר לבצע את הפעולה רק כאשר `roll` נמצאת ב-`available_actions`.
- תוצאת הקובייה היא מספר שלם אקראי בין 1 ל-6.
- רק השחקן שמזההו `current_player_id` זז; מיקומי יתר השחקנים אינם משתנים.
- המיקום החדש הוא `(המיקום הקודם + תוצאת הקובייה) % 16`, ולכן הוא תמיד 0–15.
- כאשר הסכום מגיע ל-16 או יותר, השחקן עבר דרך Start ומקבל בדיוק 200 כסף.
- לאחר הזריקה יש להחליף את `available_actions` בדיוק ל-`["end_turn"]`. כך השחקן אינו יכול לזרוק שוב, והפעולה היחידה שהוא יכול לבצע היא סיום התור.

פעולת `end_turn` עצמה תתווסף בתרגיל 5. בתרגיל הנוכחי נדרש רק לסמן שלאחר הזריקה הפעולה הבאה היא `end_turn`.

## אירועים ושגיאות

בכל זריקה מוצלחת יש ליצור **מחרוזת אירוע אחת בלבד**, לאחר שחישבתם את תוצאת הקובייה ואת המיקום החדש. המחרוזת צריכה לכלול:

- את שמו האמיתי של השחקן הנוכחי, למשל `Ada` — לא את המילה הכללית `Player`.
- את תוצאת הקובייה.
- את המיקום החדש שאליו השחקן הגיע.

השתמשו במבנה הבא:

```text
<player> rolled <1-6> and moved to <0-15>
```

לדוגמה, אם Ada התחילה במיקום 0, זרקה 4 והגיעה למיקום 4, האירוע יהיה:

```text
Ada rolled 4 and moved to 4.
```

אם השחקן עבר דרך Start, יש להוסיף **לאותה מחרוזת אירוע** גם את הטקסט המדויק `received 200 for Start`. לדוגמה, אם Ada התחילה במיקום 14, זרקה 4 והגיעה למיקום 2:

```text
Ada rolled 4 and moved to 2. Ada received 200 for Start.
```

לאחר שהמחרוזת הושלמה, יש לבצע את שני העדכונים הבאים:

1. להוסיף את המחרוזת פעם אחת בלבד לסוף `event_log`.
2. להציב את אותה מחרוזת בדיוק ב-`last_event`.

אין להוסיף קודם אירוע תנועה חלקי ואז אירוע נוסף עבור הבונוס. במקרה של מעבר ב־Start, פרטי התנועה והבונוס חייבים להופיע יחד באותה רשומה ב-`event_log`.

ניסיון לבצע `roll` נוסף באותו תור מחזיר `409` עם הודעה מתאימה שמסבירה את השגיאה, ואינו משנה את מצב המשחק.

## כיצד לוודא שהתרגיל הושלם

השוו מצב לפני ואחרי זריקה: חלצו את המספר והיעד מהאירוע, חשבו את המיקום הצפוי ודאו שרק השחקן הנוכחי זז. לבסוף נסו לזרוק פעמיים והשוו את המצב לפני ואחרי השגיאה. בדיקת מעבר Start לאורך מספר תורות תתווסף בתרגיל 5, לאחר מימוש `end-turn`.
