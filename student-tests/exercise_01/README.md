# תרגיל 1: בדיקת תקינות השירות

## מטרת התרגיל

ליצור שירות HTTP פעיל שמחזיר תשובת JSON קבועה. זהו החוזה הראשון שבאמצעותו ה-UI ומערכת הבדיקות יודעים שה-Backend זמין.

## נקודת הקצה הנדרשת

### `GET /api/health`

הבקשה אינה כוללת גוף. התגובה חייבת להיות:

- קוד HTTP ‏`200`.
- גוף JSON זהה בדיוק ל:

```json
{"status": "ok"}
```


## כיצד לוודא שהתרגיל הושלם
הפעילו את השרת, פתחו את "מעבדת הבדיקות" ב-UI, הזינו את כתובת ה-API והריצו את תרגיל 1. ודאו שהתקבלו `200`, תוכן מסוג JSON והגוף המדויק שמופיע למעלה.
