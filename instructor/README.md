# Instructor Materials

This directory is organizational, not private. Students with repository access can read it.

- \`solution-api/\` contains the complete reference backend.
- \`edge-tests/\` contains visible instructor-focused behavior checks.
- `../student-tests/exercise_01/README.md` through `exercise_09/README.md` define the student-visible requirements matched by the checkpoints.

Use a private course system for hidden assessments. Do not treat this folder as an access-control boundary.
