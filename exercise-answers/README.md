# Exercise Answers

This folder contains instructor-facing Hebrew answer guides for all eight Sigit Empire backend exercises. Each Word document includes:

- a concise restatement of the exercise and its acceptance criteria;
- a plain-language explanation of the solution;
- focused Python and FastAPI code for the capability introduced in that exercise;
- verification requests and the matching UI checkpoint.

The exercises are cumulative. Code shown in a later document assumes the capabilities from earlier exercises already exist. The complete executable implementation remains in `instructor/solution-api/`.

Regenerate the documents from the repository root with:

```bash
node scripts/generate_hebrew_exercise_answers.js
```
